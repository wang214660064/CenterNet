## 2026-08-09：分解Car 3D AP误差来源

- 新增 `src/tools/analyze_stereo_errors.py`，读取完整评估结果和SGBM逐目标记录，无需重复模型推理；
- Car Moderate条件目标二维匹配率95.40%，匹配目标平均2D IoU为0.802，说明二维检测不是当前首要瓶颈；
- 最终深度MAE为0.98m，SGBM基线MAE为1.45m，最终深度在71.52%的有效目标上优于SGBM；
- 30～50m最终深度MAE升至1.48m，且只有51.38%的目标优于SGBM，是园区关注距离内最明显的深度退化区间；

- 反事实替换真值后，深度可使平均3D IoU提升0.112，朝向提升0.017，尺寸没有稳定净提升；当前优化优先级为深度融合、遮挡检测、朝向，最后才是尺寸。
